# deep-research

Multi-source research workflow for primary-source analysis, counter-evidence, cross-source verification, and cited decision reports.

## 安装

从 GitHub 装（需要本机有 `git`）：

```bash
npx skills add SeaWork-Labs/deep-research#v1.1.4 --skill deep-research
```

从市场索引装（纯 HTTPS，国内网络可达）：

```bash
npx skills add https://skills.seaharness.cn --skill deep-research
```

## 内容

技能正文在 `skills/deep-research/payload/`。这些文件由转换器从市场归档逐字节搬来，改动请直接改 `skills/deep-research/payload/`，不要反向同步。版本以 git tag 为准。
